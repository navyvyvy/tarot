# NORU 타로

한국어 라이더-웨이트 타로 리딩 웹 앱입니다. 빌드 단계나 런타임 의존성 없이 HTML, CSS, JavaScript로 동작합니다.

## 기능

- 메이저 22장, 마이너 56장, 전체 78장 덱
- 1장, 3장, 파이브크로스, 매직세븐, 켈틱크로스 스프레드
- 역방향 확률 설정과 카드별 상세 해석
- 78장 전체의 RWS 도상 설명
- 생년월일 기반 탄생 카드
- 키보드 조작, 네이티브 다이얼로그, 모션 감소 설정 지원
- 설치 가능한 PWA와 78장 카드 이미지 오프라인 캐시

## 실행

별도 설치는 필요하지 않습니다. 서비스 워커를 사용하므로 파일을 직접 열지 말고 로컬 HTTP 서버에서 실행하세요.

```bash
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 확인

Node.js 20 이상에서 다음 명령을 사용할 수 있습니다.

```bash
npm test
npm run check
```

테스트는 셔플과 탄생 카드 계산, 78장 이미지 매핑, 서비스 워커 앱 셸 경로를 확인합니다.

## 자료 근거

카드 도상 설명과 켈틱 크로스의 위치 의미는 A. E. Waite의 1910년 《The Pictorial Key to the Tarot》와 Pamela Colman Smith의 RWS 그림을 기준으로 정리했습니다. 매직 세븐은 The Church of Light가 1932년부터 출판한 《The Sacred Tarot》 계열의 육망성 배열을 따릅니다. 해석은 단정적인 예언이 아니라 자기 성찰을 위한 참고로 제공합니다.

## 구조

- `index.html`: 시맨틱 UI
- `css/style.css`: 반응형 디자인
- `app.js`: 화면 흐름과 렌더링
- `core.js`: 셔플과 탄생 카드 순수 로직
- `card.js`: 카드 식별자와 로컬 이미지 매핑
- `locale/ko.js`: 한국어 UI와 카드 해석
- `assets/`: 78장 WebP 카드 이미지
- `sw.js`: 앱 셸과 카드 이미지 캐시

## 오프라인 동작

첫 온라인 방문에서 앱 셸과 카드 이미지 78장을 `noru-v18` 캐시에 저장합니다. 이후 탐색 요청은 네트워크를 먼저 확인하고, 연결이 없으면 캐시된 `index.html`로 돌아갑니다. 정적 파일은 캐시를 우선 사용합니다.

서비스 워커를 변경할 때는 `sw.js`의 `CACHE_NAME`을 올리면 이전 NORU 캐시만 정리됩니다.
