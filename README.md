# 🦌 NORU — 타로 카드 웹 앱

> 새벽 안개 속 노루처럼, 고요히 운명과 마주하다.

라이더-웨이트 타로 덱을 기반으로 한 한국어 타로 리딩 웹 애플리케이션입니다.
빌드 도구(Webpack, Vite 등) 없이 순수 Vanilla JS와 CSS로 작성되었으며, **100% 로컬 오프라인 환경(Local-First)**을 지원하는 최적화된 PWA(Progressive Web App)입니다.

---

## ✨ 주요 기능

### 타로 리딩
- **5가지 스프레드** — 원 카드 · 쓰리 카드 · 파이브 크로스 · 매직 세븐 (육망성) · 켈틱 크로스 (10장)
- **3종 덱** — 메이저 아르카나(22장) / 마이너 아르카나(56장) / 전체 78장
- **역방향 확률 슬라이더** — 0~100% 자유 조절 (기본값 50%, 전통 타로 기준)
- 카드 클릭 시 상세 해석 모달 (정방향 · 역방향 · 연애 · 직업)
- 모달 내 카드 이미지 클릭 시 전체화면 확대
- 결과 확인 후 추가 카드 뽑기
- 모바일 터치 드래그 + 마우스 드래그 + 휠 스크롤 지원

### 탄생 카드
- 생년월일로 나만의 타로 탄생 카드 계산 (Labyrinthos 방식)
- 메이저 아르카나 1~21번 전체 해석 (1~9 단일 카드 포함)
- 숫자 19 → 태양 · 수레바퀴 · 마법사 3장 삼위일체(Trio) 특별 처리

### 카드 이미지 (Local-First)
- **외부 CDN 의존성 Zero** — 78장의 카드 이미지가 프로젝트 내부(assets/)에 완전 내장되어 오프라인에서도 즉각 로드됩니다.
- 언어 데이터 스펙(ace, page 등)과 실제 로컬 이미지 파일명(01, 11 등)을 완벽하게 이어주는 독립 매핑 브릿지(cards.js) 적용.

## 🗂️ 파일 구조

불필요한 Depth를 제거하고 직관적인 개발을 위해 구조가 평탄화(Flatten)되어 있습니다.

- assets/ : 타로 카드 이미지 (78장 전체 로컬 내장)
- index.html : 앱 메인 뼈대 및 UI
- style.css : UI 디자인 및 레이아웃
- app.js : 메인 구동 로직 및 애니메이션 제어
- cards.js : 카드 식별자 및 로컬 이미지 파일명 매핑 데이터
- locale/ko.js : 한국어 텍스트, 해석 데이터 (다국어 확장용)
- manifest.json : PWA 설치 및 네이티브 앱화 설정
- sw.js : 서비스 워커 (강력한 캐싱 및 오프라인 구동)
- icon-192.svg : PWA 모바일 아이콘
- README.md : 프로젝트 설명 문서

## 🚀 실행 방법

### 로컬 테스트
별도의 의존성 설치(npm install 등)가 필요 없습니다. 로컬 서버 환경에서 실행하세요.
- 예시 1 (Node.js 환경) : npx serve .
- 예시 2 (Python 환경) : python3 -m http.server 8080

### 배포
GitHub Pages, Vercel, Netlify 등 정적 웹 호스팅 서비스에 폴더 전체를 업로드하면 끝납니다.
(※ PWA의 '앱 설치' 기능은 HTTPS 환경에서만 활성화됩니다.)

### 버전 업데이트 (캐시 무효화)
앱 업데이트 시, 일반 새로고침(F5)만으로도 사용자가 최신 버전을 볼 수 있도록 index.html은 Network First로 동작합니다.
단, 디자인이나 로직이 크게 바뀌어 로컬 캐시를 강제 청소해야 할 경우 sw.js 파일 최상단의 버전을 올립니다.
- 예시 : const CACHE_NAME = 'noru-v4'; (이전 버전에서 숫자 하나만 올리면 기존 캐시가 자동 삭제됨)

## 🌐 다국어 지원 (i18n)

UI 텍스트, 카드 이름, 해석 등 모든 글자 데이터는 locale/ko.js에 완벽하게 격리되어 있습니다.

### 번역 방법
1. 기존 한국어 파일을 복사하여 새로운 언어 파일을 생성합니다. (예: locale/en.js)
2. 생성한 파일 내부의 텍스트들을 번역합니다.
3. index.html의 스크립트 로드 태그 경로를 번역된 파일 경로로 교체하면 앱 전체 언어가 즉시 변경됩니다.

### 언어-이미지 분리 아키텍처
언어 파일(ko.js)은 각 언어의 문법 구조에 맞게 자유롭게 번역되며, 카드 이미지를 불러올 때는 cards.js가 브릿지 역할을 하여 각 언어에 종속되지 않고 정확한 로컬 이미지를 찾아냅니다.

## 📱 PWA 및 캐싱 전략

스마트폰에서 '홈 화면에 추가'하면 주소창이 사라지고 독립된 네이티브 앱처럼 동작합니다.

### 진보된 캐싱 전략 (Service Worker)
과거 버전의 고질적인 '새로고침 캐시 꼬임' 문제를 완벽하게 해결했습니다.

- index.html (메인 문서) ➔ [Network First] 앱 접속/새로고침 시 항상 서버에서 최신 버전을 확인하여 업데이트 누락 방지
- assets/, css, js, 폰트 ➔ [Cache First] 78장의 카드 이미지와 스크립트를 최초 1회만 다운로드 후 즉시 로드 (초고속 오프라인 구동)

- 언어 : HTML5 · CSS3 · Vanilla JS (무의존성 순수 자바스크립트)
- 폰트 : Pretendard (본문) · Cinzel (제목) · Libre Baskerville (이탤릭)

## ♿ 접근성 (A11y)

- WCAG 2.1 기준 적용: 스크린리더를 위한 완벽한 시맨틱 마크업.
- role, aria-label, aria-checked, aria-valuenow 등 50개 이상의 aria 속성 적용.
- 모달 포커스 트랩: 모달이 열리면 포커스가 모달 내부로 한정되며, 닫힐 때 원래 호출 요소로 정확히 복귀.
- Tab 키를 이용한 완벽한 키보드 내비게이션 및 ESC 키 닫기 지원.
- maximum-scale 제한 제거로 저시력자를 위한 모바일 핀치 줌(확대) 전면 허용.

## 🔧 주요 기술 구현

- 모듈 분리 최적화 : HTML 내부의 방대한 스크립트와 스타일을 app.js 및 style.css로 완벽 분리하여 유지보수성 극대화.
- 에러 토스트 (Toast) : 카드 셔플이나 렌더링 중 오류 발생 시 시각적 알림 제공 (aria-live="polite" 스크린리더 지원).
- 동적 그리드 레이아웃 : 선택한 스프레드 배열(원 카드, 켈틱 크로스 등)에 맞춰 최적의 위치와 크기를 자동 계산하여 렌더링.
- 프로덕션 로거 : 개발 환경(localhost, 127.0.0.1)에서만 콘솔을 출력하고, 실제 서비스 배포 시 콘솔 출력을 완벽히 억제.
