# NORU 타로

한국어 라이더-웨이트 타로 카드 웹 앱입니다. 빌드 단계나 런타임 의존성 없이 HTML, CSS, JavaScript로 동작합니다.

## 패치 기록

### v1.0.1 · 2026-08-30

- 일반·애정·직업·금전 프리셋과 개선된 스프레드 선택 화면을 추가했습니다.
- 셔플·공개 애니메이션을 복원하고, 선택한 카드에 스프레드 순서를 표시하도록 개선했습니다.
- 카드 이미지 비율과 반응형 배치를 바로잡고 글자 잘림, 줄바꿈, 타이포그래피 위계를 정리했습니다.
- 카드 상세 해석과 종합 평가를 보강하고, 카드 이미지가 포함된 결과 요약·공유 화면을 추가했습니다.
- 메이저·마이너 78장 카드 사전과 탄생 카드 흐름을 추가했습니다.
- 상세 보기·사전·요약 코드를 분리하고 PWA 캐시와 데스크톱·모바일 자동 테스트를 정비했습니다.

## 기능

- 메이저 22장, 마이너 56장, 전체 78장 덱
- 1장, 3장, 파이브크로스, 매직세븐, 켈틱크로스 스프레드
- 역방향 확률 설정과 카드별 상세 해석
- 일반·애정·직업·금전 주제 프리셋
- AI 없이 카드와 위치를 조합하는 결과 화면, 공유 전용 링크와 PNG 저장
- 이름·키워드·수트로 찾는 78장 카드 사전
- 78장 전체의 RWS 도상 설명
- 생년월일 기반 탄생 카드
- 키보드 조작, 네이티브 다이얼로그, 모션 감소 설정 지원
- 설치 가능한 PWA와 78장 카드 이미지 오프라인 캐시

## 실행

별도 설치는 필요하지 않습니다. 서비스 워커를 사용하므로 파일을 직접 열지 말고 로컬 HTTP 서버에서 실행하세요.

```bash
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

## 확인

Node.js 20 이상에서 다음 명령을 사용할 수 있습니다.

```bash
npm test
npm run check
```

실제 브라우저 흐름과 모바일 화면까지 확인하려면 의존성을 설치한 뒤 E2E 테스트를 실행합니다.

```bash
npm install
npm run test:e2e
```

테스트는 셔플과 탄생 카드 계산, 결과 요약, 78장 이미지 매핑, 서비스 워커 앱 셸 경로, 카드 사전, 켈틱 크로스 배열과 반응형 화면을 확인합니다.

## 자료 근거

카드 도상 설명과 켈틱 크로스의 위치 의미는 A. E. Waite의 1910년 《The Pictorial Key to the Tarot》와 Pamela Colman Smith의 RWS 그림을 기준으로 정리했습니다. 매직 세븐은 The Church of Light가 1932년부터 출판한 《The Sacred Tarot》 계열의 육망성 배열을 따릅니다. 탄생 카드는 월, 일, 출생 연도의 앞·뒤 두 자리를 더한 뒤 21 이하로 줄이는 Tarot School 계열의 페어 방식을 사용하며, 19는 19·10·1의 세 장으로 읽습니다. 해석은 단정적인 예언이 아니라 자기 성찰을 위한 참고로 제공합니다.

## 구조

- `index.html`: 시맨틱 UI
- `css/style.css`: 반응형 디자인
- `app.js`: 화면 흐름과 렌더링
- `detail.js`: 카드 상세 보기와 이미지 확대
- `dictionary.js`: 78장 카드 검색과 필터
- `core.js`: 셔플과 탄생 카드 순수 로직
- `card.js`: 카드 식별자와 로컬 이미지 매핑
- `locale/ko.js`: 한국어 UI와 카드 해석
- `assets/`: 78장 WebP 카드 이미지
- `sw.js`: 앱 셸 사전 캐시와 카드 이미지 런타임 캐시

## 오프라인 동작

첫 온라인 방문에서는 앱 셸만 `noru-v57` 캐시에 저장합니다. 카드 이미지는 실제로 본 카드부터 같은 캐시에 저장하므로 첫 설치에서 78장을 한꺼번에 내려받지 않습니다. 이후 탐색 요청은 네트워크를 먼저 확인하고, 연결이 없으면 캐시된 `index.html`로 돌아갑니다. 정적 파일은 캐시를 우선 사용합니다.

서비스 워커를 변경할 때는 `sw.js`의 `CACHE_NAME`을 올리면 이전 NORU 캐시만 정리됩니다.
